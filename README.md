# graphviz-pure.github.io

Publishes https://graphviz-pure.github.io/, the documentation site of
[graphviz-pure](https://github.com/graphviz-pure/graphviz-pure). The site is built there by CI;
`.github/workflows/deploy.yml` deploys the latest successful build of `master` every 15 minutes
(or on demand). Nothing else lives here: change the site in the main repository (`site/`).
